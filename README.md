# demothree.js
¿Para qué sirve?
Para crear gráficos 3D interactivos en el navegador de manera sencilla usando JavaScript.

¿Qué problemas resuelve?

Simplifica el uso de WebGL (que es complejo y de bajo nivel).

Facilita la creación y manejo de escenas, cámaras, luces, materiales y animaciones 3D.

Permite hacer proyectos 3D sin instalar programas externos, solo con el navegador.

¿Dónde se usa?

Videojuegos en la web.

Visualización de productos (e-commerce).

Arquitectura y recorridos virtuales.

Arte y experiencias interactivas.

Realidad Virtual (VR) y Aumentada (AR).
